# Argus web panel

Management UI built with [shadcn/ui](https://ui.shadcn.com). Layout and components follow the design system aligned with the official Figma kit: [Figma — shadcn/ui](https://ui.shadcn.com/docs/figma).

## UI rule

- **Only** components from the shadcn registry (`npx shadcn add …`).
- Tokens, radius, and theme via `components.json` and CSS variables in `src/index.css`.
- New screens: combine existing primitives (Card, Sidebar, Table, Chart, Tabs) before custom CSS.

## Development

```bash
npm install
npm run dev
```

The Vite proxy forwards `/api` and `/health` to the hub (default `http://127.0.0.1:8080`).

Default locale is English. The language switcher stores `pt-BR` in `localStorage`.

```bash
npm run test
```

Runs without a hub (`fetch` is mocked in unit tests).

## Build

```bash
npm run build
```

Artifact in `dist/` — serve via nginx with a proxy to the hub.

## Layout

```
src/
  components/layout/   shell + sidebar
  components/ui/       shadcn (generated by the CLI)
  pages/               panel routes
  locales/             en.json and pt-BR.json
  lib/api.ts           hub HTTP client
```
